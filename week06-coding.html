Solution · 参考补全（中文注释 = 为什么）
<?php
abstract class Employee
{
    // 【为什么】name 用 protected：题目要求子类 Manager 的方法里写 $this->name

    // 【为什么】签名照抄老师：: string / : void / : float

    {

    }
    public function setName(string $name): void
    {
        $this->name = $name;
    }
    public function getSalary(): float
    {
        return $this->salary;
    }
    public function setSalary(float $salary): void
    {
        $this->salary = $salary;
    }
}

Step 2 · Latte constructor (augmentation) 子类构造与增强

Solution · 参考补全（中文注释 = 为什么）
<?php

class Latte extends Beverage
{
    private int $shots;

    // 【为什么】子类参数比父类多一个 → 先 parent::__construct($name)
    // 【为什么】让父类把 $name 初始化好，子类只管自己的新参数
    // 【为什么】这就是老师注释里的 augmentation（增强）
    // 【为什么】漏掉这行 = Latte 对象里没有 name —— 考试常见扣分坑
    public function __construct(string $name, int $shots)
    {
        parent::__construct($name);
        $this->setShots($shots);
    }

    // 【为什么】setShots 是子类新增的方法，父类没有 → promotion（扩展）
    // 【为什么】构造函数里也走 setter，保持"赋值只走一条路"的写法
    // 【为什么】与老师 setCalories(int $calories) 同款：不写返回类型
    public function setShots(int $shots)
    {
        $this->shots = $shots;
    }
}
